# 營運日常

模擬遊戲營運人員的一天:看數據、處理突發事件、規劃活動、填日報。讓一般玩家玩一玩就懂「營運在做什麼」。

- 模式:劇情(10 天試用期,一局約 5 到 8 分鐘,每季分籌備/上線/維運/檢討四階段)/ 無限(每 10 天一次季度考核)
- 難度:簡單 / 普通 / 困難
- 看輿情:每天一次,整理成輿情報告,冒出三件事、只顧得了一件(有好處也有代價,有的效果會持續幾天);也會讓事件先看得出氣氛
- 每局隱藏的老闆與玩家社群性格,加上每件事各自的氣氛:同一個選擇,在不同的對象面前結果不同,要從反應裡摸索
- 選完馬上有反應:大字評價(大成功/順利/不太妙/搞砸了)加上受影響的數值;連續三次選中對方胃口會進入「默契」,好的結果多 50%
- 部分事件會多一個高風險高報酬的選項(不加任何標示,要自己判斷):高風險高報酬(贏了大賺、輸了大賠),選中對方胃口的做法會讓勝算變高
- 個人風格:每局用到的做法會累積成跨局的熟練度(七種風格、各三級),帶來稱號與加成;單局累積有上限,所以得多玩幾局、也不用只練一種
- 同事卡:個人風格可以打包成一段代碼(只含稱號與風格值,不含名字),朋友貼進自己的遊戲,你的風格就成為他這局的同事:擅長的做法每天幫忙分擔一次,但偶爾也會自作主張闖點小禍;同事會坐在辦公室(螢幕後探頭、茶水間裡),依擅長的風格換配件、說口頭禪,還會帶來只有他才有的事(請教、牽線、帶消息,有的能揭露老闆或社群的性格)。全程不連線,代碼自己交換
- 職級與技能樹,可跨局累積
- 像素「場景」模式(預設)與「簡易」模式
- 在辦公室裡處理事件時:數字鍵選選項、空白鍵或 Enter 繼續到下一件
- 全部內容為虛構,存檔只放在瀏覽器本機

## 開發

```bash
npm install
npm run dev      # 開發伺服器
npm run check    # 型別檢查
npm run build    # 輸出到 dist/
npx tsx scripts/fulltest.ts   # 內容與對局完整測試
npx tsx scripts/personatest.ts   # 個人風格檢查
```

事件與活動內容在 `src/content/*.json`,規則在 `src/engine.ts`。

更新紀錄在 [開發日誌.md](開發日誌.md)。
