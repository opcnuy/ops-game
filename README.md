# 營運日常

模擬遊戲營運人員的一天:看數據、處理突發事件、規劃活動、填日報。讓一般玩家玩一玩就懂「營運在做什麼」。

- 模式:劇情(10 天試用期,一局約 5 到 8 分鐘,每季分籌備/上線/維運/檢討四階段)/ 無限(每 10 天一次季度考核)
- 難度:簡單 / 普通 / 困難
- 職級與技能樹,可跨局累積
- 像素「場景」模式(預設)與「簡易」模式
- 全部內容為虛構,存檔只放在瀏覽器本機

## 開發

```bash
npm install
npm run dev      # 開發伺服器
npm run check    # 型別檢查
npm run build    # 輸出到 dist/
npx tsx scripts/fulltest.ts   # 內容與對局完整測試
```

事件與活動內容在 `src/content/*.json`,規則在 `src/engine.ts`。
